# CredEx outreach kit

These drafts are for exploratory outreach only. They do not imply that any developer, university, employer, or institution has agreed to participate. Personalize each message and send it only to an appropriate contact.

## 1. Developer testing invitation

**Subject:** Looking for developer feedback on CredEx (open-source skill verification prototype)

Hi,

I'm building CredEx, an open-source prototype exploring interoperable skill and credential verification using a Beckn-style BAP/BPP architecture.

I'm looking for a few developers to review the repository and try the local synthetic-data walkthrough. I'd especially value feedback on setup, API clarity, security assumptions, and the integration design.

The project is still experimental, and I'm not asking anyone to use real student records or treat its verification output as authoritative. If you're interested, the repository and contribution guide are here:

https://github.com/Basalingappa-Patil/credex-app

If you have time, I'd appreciate either a short review or an issue describing what was confusing or missing. There is no expectation to contribute code.

Thank you,
CredEx maintainer

## 2. Institution discovery request

**Subject:** Exploratory discussion: interoperable academic credential verification

Hello,

I'm developing CredEx, an open-source prototype exploring how educational institutions and employers might exchange and verify skill or credential information through interoperable workflows.

I'm reaching out to ask whether someone from your team who works with academic records, examination systems, placements, or digital credentials might be available for a brief exploratory discussion.

At this stage, I am not requesting student data, system access, or institutional endorsement. I would like to understand your current verification process, operational challenges, privacy requirements, and what evidence would be needed to evaluate a small synthetic-data demonstration.

The project is available at:
https://github.com/Basalingappa-Patil/credex-app

I would be grateful for the opportunity to learn from your experience. Any discussion would be exploratory and would not be represented as a partnership without your explicit permission.

Regards,
Basalingappa Patil
CredEx maintainer
